# Kura Agent Harness Hub

Welcome to the **Kura Agent Harness**.

## Workflows and Skills
1. **Full Development Loop**: [kura-dev](../kura-dev/SKILL.md) — Orchestrator coordinating planning, seam decisions, and the 4-agent TDD cycle (test-writer, code-fixer, validator).
2. **Backlog & Planning**: [kura-backlog-planning](../kura-backlog-planning/SKILL.md) — Requirements intake, `backlog/inbox.md`, `open-questions.md`, and hierarchical micro-task decomposition.
3. **Ponytail Mode**: [kura-ponytail](../kura-ponytail/SKILL.md) — Lazy senior dev mode (smallest complete change, ruthless YAGNI, deletion beats addition).
4. **Hooks Setup**: [kura-hooks-setup](../kura-hooks-setup/SKILL.md) — Set up repo hooks for output firewall, blocked commands, and lady-lens search guards.
5. **Rules Ratchet**: [kura-rules-setup](../kura-rules-setup/SKILL.md) — Configure `.kura/rules.json` and initialize `.kura/baseline.json`.
6. **Code Graph Setup**: [kura-lens-setup](../kura-lens-setup/SKILL.md) — Automated setup and verification of lady-lens code graph MCP tooling.
7. **Architecture Standards**:
   - [kura-js-architecture](../kura-js-architecture/SKILL.md) — Hexagonal Ports & Adapters, contract testing for JS/TS.
   - [kura-csharp-architecture](../kura-csharp-architecture/SKILL.md) — SOLID, DDD immutable records, mediator2 for C# .NET.
8. **Communication**: [kura-caveman](../kura-caveman/SKILL.md) — Ultra-concise, high-density token-saving communication.
